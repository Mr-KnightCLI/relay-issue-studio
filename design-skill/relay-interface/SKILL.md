---
name: relay-interface
description: Extend the Relay GitHub issue triage interface while preserving its issue-review workflow, copper visual system, and accessible motion.
---

Keep repository identity, issue number, and review state visible when extending the queue or detail view. Preserve the distinction between imported GitHub data, sample issues, and decisions stored in this browser. Label suggestions as suggestions until a maintainer reviews them.

Use copper accents for focus, selection, and the layered sculpture. Carry the existing typography and surface colors into new views. Keep decorative motion outside the reading column and give reduced-motion users a still composition.

When changing the layout, check a narrow viewport with a long issue title, keyboard selection of an issue, and a repository request that fails. Preserve access to the current queue when an import fails.
