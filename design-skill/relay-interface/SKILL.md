description: Extend the Relay GitHub issue dashboard while preserving its issue-review workflow, lime status cards, and keyboard-friendly ledger.
---

Keep repository identity, issue number, and review state visible when extending the queue or detail view. Distinguish imported issues, sample issues, and decisions stored in the browser. Label suggestions as suggestions until a maintainer reviews them.

Use the existing warm gray surfaces, black and lime summary cards, and typography-led issue ledger. Keep the icon rail accessible through named controls, and preserve a readable label or another non-color indicator for selected rows and status. Derive displayed totals from the active repository data.

Check a narrow viewport with a long issue title, keyboard selection of an issue, and a repository request that fails. Preserve access to the current queue when an import fails.
